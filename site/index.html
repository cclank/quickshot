三步装好，一分钟上手。Three steps, one minute.

1

拖进“应用程序”Drag to Applications

打开 DMG，把 QuickShot 拖到“应用程序”文件夹。Open the DMG and drag QuickShot onto the Applications folder.

2

首次打开被拦截？Blocked on first launch?

QuickShot 暂未经过 Apple 公证，macOS 可能提示“无法验证开发者”。在“终端”运行下面这行后重新打开即可，只需一次：QuickShot is not notarised by Apple yet, so macOS may say it cannot verify the developer. Run this once in Terminal, then open it again:

sudo xattr -rd com.apple.quarantine /Applications/QuickShot.app

也可以在“系统设置 → 隐私与安全性”底部点“仍要打开”。Or choose “Open Anyway” at the bottom of System Settings → Privacy & Security.

3

跟着指引授权Follow the guide

欢迎指引会展示快捷键，并带你允许“屏幕录制”：把系统设置下方出现的 QuickShot 图标拖进列表，就完成了。The welcome guide shows the shortcut and walks you through Screen Recording: drag the QuickShot icon that appears under System Settings into the list, and you are done.

Windows：运行安装程序即可；如果出现 SmartScreen 提示，点“更多信息 → 仍要运行”。Windows: run the installer. If SmartScreen appears, choose “More info → Run anyway”.

常见问题FAQ

还有疑问？Questions?

QuickShot 免费吗？Is QuickShot free?
免费。源代码以 GPL-3.0 许可证公开在 GitHub，欢迎提交 Issue 和 Pull Request。Yes. The source code is on GitHub under the GPL-3.0 license, and issues and pull requests are welcome.
截图会上传到云端吗？Are my screenshots uploaded anywhere?
不会。QuickShot 没有联网代码、账号或统计，截图、标注、美化和文字提取都在本机完成。No. QuickShot has no network code, accounts or analytics. Capturing, annotating, styling and text extraction all happen on your computer.
为什么提示“无法验证开发者”？Why does macOS say it cannot verify the developer?
QuickShot 目前没有 Apple 开发者签名与公证，macOS 会拦截首次打开。在“终端”运行 sudo xattr -rd com.apple.quarantine /Applications/QuickShot.app，或在“系统设置 → 隐私与安全性”底部点“仍要打开”，之后就不会再出现。QuickShot is not yet signed and notarised with an Apple developer ID, so macOS blocks the first launch. Run sudo xattr -rd com.apple.quarantine /Applications/QuickShot.app in Terminal, or choose “Open Anyway” in System Settings → Privacy & Security. You only need to do this once.
需要哪些权限？Which permissions does it need?
macOS 上只需要“屏幕录制”，用来看到屏幕上的内容。首次启动的指引会一步步带你完成：把 QuickShot 图标拖进系统设置的列表即可。Windows 不需要额外权限。On macOS, only Screen Recording, so it can see what is on screen. The first-launch guide walks you through it: drag the QuickShot icon into the list in System Settings. Windows needs no extra permission.
打开后在哪里找到它？Where is it after I open it?
QuickShot 常驻菜单栏（Windows 在通知区域）。按快捷键即可截图；点菜单栏图标可以切换选区方式、界面语言、登录时启动，或重新打开使用指南。QuickShot lives in the menu bar (the notification area on Windows). Press the shortcut to capture, or click the icon to switch selection mode or language, launch at login, or reopen the guide.
支持哪些系统？Which systems are supported?
macOS 12 及以上，Apple 芯片与 Intel 各有安装包；Windows 10 与 11（64 位）。Windows 上的文字提取使用系统设置中已安装的 OCR 语言。macOS 12 or later, with separate builds for Apple silicon and Intel, and Windows 10 and 11 (64-bit). Text extraction on Windows uses the OCR languages installed in Windows Settings.
